Memory & performance

Current usage
Measuring…
Preset
Restart needed
Some changes only apply after restarting Hen Browser. Open tabs are reopened.

Background tabs applies immediately

Trim memory of background tabs
Asks the engine to drop caches as soon as a tab is hidden
Suspend background tabs after
Freezes scripts and timers. Instant to resume. Tabs playing audio are skipped.
Unload background tabs after
Frees the tab completely; it reloads when you return (unsaved form input and back history are lost)

Engine needs restart

Share one browser process with the toolbar
Off runs the toolbar in a second WebView2 browser (about 80–150 MB more)
One process per site
Tabs of the same site share a renderer instead of one each
Renderer process limit
Fewer processes use less memory; sites start sharing processes past the limit
Disable back/forward cache
Stops keeping previous pages alive in memory; Back reloads the page instead
Low-end device mode
Smaller caches and GPU buffers. Saves the most; scrolling and animations may get less smooth
Disable background networking
No browser-internal pre-connects or service pings (pages and extensions are unaffected)
JavaScript heap limit per tab
Caps runaway pages. Heavy web apps can crash when they hit a low limit

Appearance

Dark mode
Same accent palette, dark surfaces. Websites that support dark mode follow along.
Follow ChickenWM theme
Use whatever light/dark mode the system theme is set to (Settings → Appearance in ChickenWM)
Match website colors
Switch the toolbar to light or dark depending on the background of the page you're viewing
Auto-hide vertical tabs
The sidebar tucks away to a thin strip; hover the left edge to slide it out over the page
Animations

Theme gradient
A soft, slowly drifting wash of your ChickenWM accent colors behind the toolbar and tabs
Ambient colors

Grain
A fine film-grain texture over the browser's surfaces
Custom styling
